# Spec Delta

## Purpose

Даёт автоматические метрики качества синтезированной речи — насколько она похожа на целевого говорящего и насколько разборчива. Они нужны, чтобы сравнивать конфигурации и чекпоинты Голоса без ручного прослушивания каждого варианта.

## ADDED Requirements

### Requirement: Похожесть спикера
Для синтезированного файла и набора эталонных записей целевого говорящего метрика SHALL вычислять похожесть как косинусное сходство эмбеддингов спикера, усреднённое по эталонам.

#### Scenario: Сравнение с эталонами
- **WHEN** на вход поданы синтезированный WAV и 5 эталонных записей
- **THEN** на выходе одно число от −1 до 1 и разброс по эталонам

### Requirement: Опорный уровень похожести
Метрика SHALL уметь вычислять похожесть «реальная запись ↔ реальная запись» того же говорящего. Это опорный уровень, с которым сравнивается синтез.

#### Scenario: Опорный уровень
- **WHEN** на вход подан набор эталонных записей одного говорящего
- **THEN** метрика выдаёт среднюю попарную похожесть между ними

### Requirement: Разборчивость
Метрика SHALL распознавать синтезированный файл стартовой моделью распознавания речи проекта и вычислять CER относительно исходного текста фразы. Перед сравнением текст MUST нормализоваться: регистр, пунктуация, ё → е.

#### Scenario: Идеальный синтез
- **WHEN** синтез произнесён чётко, и распознавание совпало с текстом
- **THEN** CER равен 0

#### Scenario: Различия только в пунктуации
- **WHEN** распознанный текст отличается от исходного только пунктуацией и буквой ё
- **THEN** CER равен 0

### Requirement: Пакетный режим
Метрики SHALL вычисляться для всего каталога результатов бенчмарка одной командой и дописываться в его файл результатов.

#### Scenario: Прогон закончен
- **WHEN** для каталога прогона запущен подсчёт метрик
- **THEN** у каждой фразы в файле результатов появляются похожесть и CER, а у конфигурации — их медианы
