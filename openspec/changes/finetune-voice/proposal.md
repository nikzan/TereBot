# Proposal

## Why

Реализует **этап 5 «Дообучение Голоса»** из `docs/PLAN.md`. Zero-shot Голос узнаваем лишь частично: похожесть 0,47–0,52 при опорном уровне «запись ↔ запись» 0,64 (`docs/benchmarks/voice-zero-shot.md`). Узнаваемость — главный приоритет проекта, и дообучение на вычитанных записях Прототипа — главный рычаг.

Датасет этапа 4 ещё не набран: после первой 5-часовой Сессии есть 19 минут вычитанной речи при цели 30–60. Ждать его целиком не нужно. Пробное обучение на неполном датасете проверит всю цепочку — данные → кластер → чекпоинт → MLX на Mac → метрики — и даст первый ответ, растёт ли похожесть. Финальное обучение повторит ту же цепочку на полном датасете.

## What Changes

- Подготовка данных для официального скрипта дообучения Qwen3-TTS (`finetuning/` из репозитория QwenLM/Qwen3-TTS): манифест train → JSONL `{audio, text, ref_audio}`, ресемплинг 48 → 24 кГц, один общий референс Прототипа на все примеры.
- Запуск дообучения Qwen3-TTS-12Hz-1.7B-Base на кластере (одна GPU RTX 5000 Ada) с чекпоинтом на каждую эпоху. Зависимости — группа uv `train`, код — только в `scripts/`.
- Оценка каждого чекпоинта: синтез текстов отложенной выборки и фиксированного набора фраз, похожесть к реальным записям Прототипа из отложенной выборки, CER, сравнение с zero-shot на том же наборе. Выбор чекпоинта по кривой метрик.
- Перенос выбранного чекпоинта на Mac: конвертация в MLX 8-bit и бенчмарк скорости и памяти с LLM, как на этапе 3.
- Слепой тест: подготовка пар «живая запись / синтез одного текста», лист ответов, подсчёт результата.
- Два прогона: **пробный** на текущем датасете и **финальный** после выполнения этапа 4. Отчёт по обоим в `docs/benchmarks/`.

**Вне рамок:** сбор и вычитка данных (этап 4, change `add-voice-dataset-pipeline`). Встраивание Голоса в ядро Клона (этап 6). Многоговорящее дообучение, LoRA и собственный цикл обучения вместо официального скрипта. Дообучение LLM. Запасные модели (0.6B, Chatterbox): только если 1.7B не уложится в RTF < 1 или память после дообучения. RVC-полировка тембра.

## Capabilities

### New Capabilities
- `voice-training`: подготовка обучающих данных из манифеста датасета, дообучение Голоса на кластере, оценка и выбор чекпоинта, перенос на Mac.
- `voice-blind-test`: проведение и подсчёт Слепого теста Голоса.

### Modified Capabilities
- `voice-benchmark`: бенчмарк умеет запускать дообученный Голос (говорящий из чекпоинта, без референса).
- `voice-quality-metrics`: эталонами похожести могут быть записи Прототипа из отложенной выборки датасета.

## Impact

- Код: `scripts/voice_train/` (подготовка данных, запуск обучения, синтез для оценки, Слепой тест), `scripts/bench_voice.py` (адаптер дообученного Голоса), `terebot.voice_eval` (эталоны из отложенной выборки).
- Зависимости: группа uv `train` — `qwen-tts==0.1.1` с `transformers==4.57.3` (пины из `docs/REFERENCES.md`), только на кластере, конфликтует с `tts-mlx`. Код дообучения QwenLM/Qwen3-TTS берётся из репозитория на закреплённом коммите, в наш репозиторий не копируется.
- Данные: `data/dataset/` переносится на кластер через rsync; чекпоинты и результаты — в `data/voice/` (вне git).
- Документы: `docs/benchmarks/voice-finetune.md`, обновления `docs/REFERENCES.md` и `docs/PLAN.md`.
- Зависит от этапа 4: пробный прогон — от текущего манифеста, финальный — от выполненного `add-voice-dataset-pipeline`.
