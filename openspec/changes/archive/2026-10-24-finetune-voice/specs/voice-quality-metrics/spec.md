# Spec Delta

## ADDED Requirements

### Requirement: Эталоны из отложенной выборки
Пакетный режим SHALL принимать набор эталонных записей как параметр. Эталонами MUST можно указать записи Прототипа из отложенной выборки датасета Голоса; тогда опорный уровень «запись ↔ запись» считается по ним же. Если эталоны не указаны, используются прежние эталоны бенчмарка.

#### Scenario: Оценка дообученного Голоса
- **WHEN** подсчёт метрик запущен для каталога синтеза с эталонами из отложенной выборки
- **THEN** похожесть каждой фразы считается к живым записям Прототипа, а в итогах указаны эти эталоны и опорный уровень по ним

#### Scenario: Прежний бенчмарк
- **WHEN** подсчёт метрик запущен без параметра эталонов
- **THEN** результат такой же, как до изменения
