# Discord-шлюз на Node, ядро Клона на Python

Discord требует E2EE (DAVE) для всех звонков с марта 2026. Приём голоса под DAVE в официальном релизе есть только у `@discordjs/voice` ≥ 0.19.2, в релизных Python-библиотеках его нет. Поэтому весь Discord-I/O (подключение, приём раздельных потоков по user ID, воспроизведение) живёт в небольшом Node-шлюзе. Распознавание, LLM, Голос и Политика Диалога — в Python-ядре. Шлюз и ядро общаются через локальный WebSocket.

## Considered Options

- **Чистый Python на форке `discord-ext-voice-recv`** (zacker150 и др.) поверх discord.py 2.7 + `davey`. Один язык, но зависимость от неслитой ветки с известными багами. **Не реализуем.** Пересмотреть, если Node-шлюз не пройдёт проверку приёма голоса либо если поддержка DAVE-receive попадёт в релиз py-cord (PR #3159) или discord-ext-voice-recv.
- **Виртуальный аудиокабель + обычный клиент Discord.** Даёт один смешанный поток без разделения по участникам, требует пользовательский аккаунт — отвергнуто.
