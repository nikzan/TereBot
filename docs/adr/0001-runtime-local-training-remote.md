# Клон работает строго локально, обучение — на отдельном кластере

Во время работы весь Клон (Discord-шлюз, распознавание речи, LLM, Голос) запускается только на локальном MacBook Pro M1 Pro с 16 ГБ памяти, без внешних API. Обучение (дообучение Голоса и при необходимости LLM) выполняется на отдельном кластере с RTX 5000 Ada (64 ГБ VRAM). Поэтому выбор моделей ограничивают 16 ГБ unified-памяти на MPS/CPU, а не мощность кластера. Задержка не критична, но на всех этапах её нужно замерять.
