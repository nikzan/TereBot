# Конвейер датасета Голоса

Превращает записи шлюза с речью Прототипа в вычитанный датасет сегментов с транскриптами, разделённый на обучающую и отложенную выборки. Записи делаются по [docs/recording-checklist.md](../../docs/recording-checklist.md), вычитка — по [docs/transcription-guide.md](../../docs/transcription-guide.md). Логика шагов — в `src/terebot/dataset/`.

Все команды — из корня репозитория, в группе uv `data`:

```bash
uv sync --group data
```

## Шаги

Каждый шаг можно перезапускать: уже сделанное он пропускает, а ручная вычитка не теряется.

**1. Нарезка.** Берёт из `data/recordings/<Сессия>/` только `<ID Прототипа>.wav` и `.segments.jsonl`, нормализует громкость к −23 LUFS, режет фрагменты речи на сегменты 3–15 с и отбраковывает короткие, клиппированные и тихие.

```bash
uv run --group data python scripts/dataset/segment.py --prototype <Discord ID Прототипа>
```

Нарезаются только Сессии, которых ещё нет в датасете, поэтому не запускайте шаг, пока идёт запись. `--force` нарезает всё заново: `seg_id` (Сессия + время начала) при тех же параметрах не меняются, и вычитка подхватится.

**2. Транскрипция.** Распознаёт новые сегменты GigaAM-v3 e2e RNNT на CPU. При первом запуске скачивает модель с Hugging Face (~1 мин).

```bash
uv run --group data python scripts/dataset/transcribe.py
```

**3. Вычитка.** Ручная, 2–4 часа на весь датасет. Прерывается клавишей `q` и продолжается с того же места.

```bash
uv run --group data python scripts/dataset/review.py
```

**4. Сборка.** Манифесты и отчёт из принятых сегментов. Можно запускать в любой момент, чтобы посмотреть, сколько уже набрано.

```bash
uv run --group data python scripts/dataset/build.py
```

После новой Сессии записи повторите шаги 1–4: обработаются только новые сегменты.

## Что получается

```
data/dataset/
  segments.jsonl          все сегменты нарезки; у отбракованных — причина в reject
  segments/<seg_id>.wav   48 кГц, моно, 16 бит, −23 LUFS
  review.jsonl            auto_text, вычитанный text, status — единственный файл с ручным трудом
  manifest/train.jsonl    {"audio", "text", "duration", "session", "seg_id"}
  manifest/holdout.jsonl  ~10% длительности, целыми 2-минутными блоками Сессий
  report.md               минуты по Сессиям, длительности, отбраковка, прогресс вычитки
```

Этап 4 готов, когда в `report.md` 30–60 минут принятой речи и вычитано 100% сегментов ([docs/PLAN.md](../../docs/PLAN.md)).

`review.jsonl` — результат часов ручной работы: перед `--force` и экспериментами сделайте копию.

## Перенос на кластер

Пути в манифестах относительные к `data/dataset/`, поэтому каталог переносится как есть. Нужны только манифесты и аудио:

```bash
rsync -av --include='segments/***' --include='manifest/***' --include='report.md' --exclude='*' data/dataset/ <кластер>:<репозиторий>/data/dataset/
```

На кластере клонируется тот же репозиторий; приведение к формату обучения конкретной модели — этап 5.
