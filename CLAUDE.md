# TereBot

Локальный голосовой Клон конкретного человека для приватного Discord-сервера на русском языке.

Перед работой прочитай:
- [CONTEXT.md](CONTEXT.md) — глоссарий. В коде, коммитах и обсуждениях используй эти термины (Клон, Прототип, Голос, Паспорт, Диалог, Собеседник…), а не слова из их списков _Avoid_.
- [docs/PLAN.md](docs/PLAN.md) — принятые решения, пороги и этапы с критериями готовности. Текущий этап — первый невыполненный.
- [docs/adr/](docs/adr/) — архитектурные решения. Отвергнутые там варианты не предлагай и не реализуй, пока не выполнено указанное в ADR условие пересмотра.
- [docs/REFERENCES.md](docs/REFERENCES.md) — первоисточники и проверенные версии. Перед тем как выбрать версию пакета, модель или API, сверься с ними и с самим первоисточником. [docs/research/](docs/research/) — фоновый обзор, во многом по вторичным источникам; на его цифры не опирайся без проверки.

Ограничения:
- Клон работает только на MacBook Pro M1 Pro с 16 ГБ памяти (MPS/CPU), без внешних API. Код с расчётом на CUDA допустим только в `scripts/` для обучения на кластере.
- Python — через uv (`uv add`, `uv run`). Node-шлюз — в `gateway/`.
- `data/` и `.env` никогда не коммить: там голос Прототипа, записи участников и токен.
- Юнит-тесты (`pytest`, `node:test`) — только на изолированную бизнес-логику и пайплайн обработки данных. Обёртки над библиотеками, разбор настроек, регистрацию команд и прочий бойлерплейт проверяй запуском реального сервиса или скрипта.
- С владельцем общайся только на русском — включая статусы, итоги и заголовки из шаблонов скиллов. Английский текст шаблона — это структура, а не язык ответа.

Работа ведётся через OpenSpec: задачи — это changes в `openspec/changes/<имя>/` (`proposal.md`, `specs/`, `design.md`, `tasks.md`). Реализация change — `/opsx:apply <имя>`: иди по `tasks.md` по порядку и отмечай `- [x]` только после проверки, указанной в задаче. Задачи с префиксом «[владелец]» не выполняй сам — остановись и попроси владельца. Новый change — `/opsx:propose`.
